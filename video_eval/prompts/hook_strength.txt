## Scoring Criteria

Rate the hook strength on a 5-level scale:

**Level 5:** Powerful visual impact combined with a clear benefit statement or curiosity trigger in the first 3 seconds. Uses techniques like dramatic transformation, unexpected visuals, direct audience address with a compelling question, or an irresistible offer. Viewer is compelled to keep watching.

**Level 4:** Strong opening with either visual impact or a verbal/textual hook. The first 3 seconds clearly communicate value or create intrigue, though one element (visual or verbal) could be stronger.

**Level 3:** Decent opening that establishes context quickly. The video starts with relevant content but lacks a strong attention-grabbing element. Viewer interest is moderate but not compelling.

**Level 2:** Weak opening. The first 3 seconds contain generic content (e.g., logo animation, slow fade-in, unrelated establishing shot) that does not create urgency or interest.

**Level 1:** No hook whatsoever. The opening is bland, confusing, or off-putting. Black frames, silence, irrelevant content, or extremely slow pacing that would cause immediate viewer drop-off.

## Output Format

Return a JSON object with the following structure:
```json
{"level": <1-5>, "reasoning": "...", "evidence": [{"modality": "visual|audio|text", "timestamp": <float|null>, "detail": "..."}], "suggestion": "..."}
```

- `level`: Integer score from 1 to 5 based on the criteria above.
- `reasoning`: Brief explanation of why this level was assigned.
- `evidence`: List of specific observations supporting the score.
- `suggestion`: Actionable improvement advice (empty string if level >= 4).
